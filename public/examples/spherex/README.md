# Explicit real example: NGC 1491

Three original IMAGE HDUs from official NASA/SPHEREx IRSA DR1/QR3 exposures, with unmodified pixels and WCS/SIP. `manifest.json` records original URLs, MJD/UTC dates and SHA-256 hashes. Catalog files are real Gaia DR3 (IRSA Gator) and CDS SIMBAD (official Harvard mirror) responses captured on 2026-11-15. NASA/SPHEREx, Caltech/IPAC, ESA/Gaia/DPAC and CDS retain their respective data credits.

This is an explicitly selected recorded example, never an automatic replacement for an unavailable live query. It covers only this small region and three dates. A common detector does not guarantee common wavelength. IMAGE alone does not include the original instrument FLAGS, VARIANCE or WCS-WAVE tables. Do not infer a calibrated spectrum or fixed-band light curve from these files. Use the original full FITS for that work.
